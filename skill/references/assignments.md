# Moodle Assignments and practical work

Use native «Задание» (Assignment) when students should submit files for teacher review. A downloadable task file goes under «Дополнительные файлы»; enable «Ответ в виде файла» for student submissions. Check allowed file count and size, submission-button behavior, deadlines, feedback methods, and grading scale. Use the requested values or inspect an approved example; do not invent a deadline. A teacher preview and a visible attachment do not prove a real student can submit or that grades persist.

When splitting a source Word document, preserve the text, tables, formatting, embedded objects, and relationships, including material needed to complete each task. Preserve source content even when it appears incorrect if requested; report concrete ambiguities separately. Check boundaries between tasks, including headings immediately before the next task, and verify each resulting document opens and renders correctly before publishing. Copying a DOCX package and removing body blocks can leave unrelated embedded data or metadata in each file: inspect and remove unnecessary private material before sharing, without breaking referenced relationships.

Follow the user's explicit placement rule even if numbering and subject matter differ. If asked for thematic mapping, compare topics first; equal counts alone do not establish a one-to-one match. Use observed UI controls to move an activity after the chosen lesson; the move dialog may require expanding the destination section. UI updates can be asynchronous or retain the previous selected row: verify the actual course order after each move and again after reload, rather than assuming a click succeeded.

An approved assignment can be duplicated to preserve settings, but the duplicate initially contains the original file and title. Replace both, confirm only the intended attachment remains, save, and verify the published filename and target activity. Reinspect the course after a timeout before creating another copy. If the interface requires a confirmation to remove a copied attachment, confirm only within the authorized edit. Avoid leaving incomplete duplicates visible to students.

Report what was verified: exact number of assignments and placement, attachment visibility, submission settings, and any untested student submission or grading. Keep the browser open if requested.
